# Sklep

Katalog zawiera kod sklepu internetowego opartego na **PrestaShop 8.2.8**.

## Konfiguracja

- `Dockerfile` – definicja obrazu Docker zawierającego aplikację PrestaShop.
- `php.ini` – dodatkowa konfiguracja PHP (jeżeli została zastosowana).

## Organizacja plików

Katalog przeznaczony jest na kod i konfigurację aplikacji.

Nie przechowujemy tutaj sekretów ani generowanych danych, takich jak cache, logi, vendor/ i zdjęcia produktów.
